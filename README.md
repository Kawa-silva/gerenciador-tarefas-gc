# Gerenciador de Tarefas

Projeto desenvolvido para a disciplina de Gerência de Configuração do curso de Engenharia de Software.

## Objetivo

Desenvolver uma aplicação simples para gerenciamento de tarefas utilizando HTML, CSS e JavaScript, aplicando boas práticas de controle de versão com Git e GitHub.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Funcionalidades

- Adicionar tarefas
- Marcar tarefas como concluídas
- Remover tarefas
- Interface simples e responsiva

## Fluxo de Desenvolvimento

O projeto foi desenvolvido utilizando Git Flow simplificado.

Branches utilizadas:

- main
- develop
- feature/interface
- feature/estilo
- feature/adicionar-tarefas
- feature/acoes-tarefas
